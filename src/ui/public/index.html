                  Вычисления
                  

                    
Где считатьРаспознавание, разбор по голосам, отделение голоса, синтез и голоса актёров — тяжёлые нейросети. На сервере с видеокартой они считаются в десятки раз быстрее, а этот компьютер остаётся свободен.

                    

                      
                      
                    

                  

                  

                  

                    
Сервер с видеокартойИмя или адрес машины, где запущен сервис dubpipe-worker (ставится scripts/server/install-worker.sh). Перевод через Ollama пойдёт в её же Ollama.

Разбор по голосам на сервереpyannote на CUDA — самая долгая стадия на процессоре.

                    

                  

                  

                    
Отделение голоса на сервереДорожка уходит на сервер и возвращается разделённой.

                    

                  

                  

                    
Синтез на сервереДля движка silero: модель голосов держится на видеокарте сервера.

                    

                  

                  

                    
Голоса актёров на сервереX-Voice. Считается только на сервере: модели нужно своё окружение (scripts/server/install-worker.sh --with-clone).

                    

                  

                  

                    
Локальный перевод на сервереOllama сервера вместо Ollama этого компьютера: для профиля offline — основной путь, для hybrid — запасной.

                    

                  

                  

                    
Освобождать видеопамять под задачуКарта общая с ComfyUI и Ollama. Когда задаче не хватает памяти, сервис выгружает простаивающий ComfyUI, затем модели Ollama — иначе задача ушла бы на процессор. Идущую генерацию ComfyUI не трогает.

                  Перевод

                  

                    
Где переводитьОблачная модель качественнее и требует ключ. Локальный вариант работает без сети через Ollama.

                    

                      
                      
                    

                  


                  

                    
Ключ доступаКлюч Kilo Code. Хранится на этом компьютере отдельно от настроек и никуда не передаётся, кроме шлюза.

                    

                      

                        
                        
                      

                      

                        
                        
                        
                        
                      

                    

                  


                  

                    
Финальная рецензия переводаЕщё один проход по всему переводу целиком: имена, род персонажей, «ты» и «вы», смысловые ошибки и реплики, не влезающие в своё время. Видит то, чего не видно внутри пакета из десяти реплик. Удваивает время и стоимость перевода.

                    

                  


                  

                    
МодельВесь каталог шлюза Kilo Code; цена — за миллион токенов запроса / ответа. Сравнить несколько на своём материале можно на вкладке «Сравнение моделей».

                    

                      

                        
                        

                      

                      

                        
                        
                        
                      

                      

                    

                  


                  

                    
Запасная модель OllamaЕсли облако недоступно, перевод пойдёт через Ollama этой моделью. Имя — как в ollama list.

                    

                  


                  

                    
Ненормативная лексикаКак переводить брань в оригинале.

                    

                      
                    

                  


                  

                    Тонкая настройка
                    

                      
Реплик в одном запросе8–12 — рекомендуемый диапазон.

                      

                    

                    

                      
Добивать короткие реплики до длины слотаТак требует ТЗ, и доля укладки выходит выше. Но чтобы попасть в длину, модель дописывает то, чего нет в оригинале: «Лиза.» превращается в «Лиза, Лиза». Выключите — короткая реплика останется короткой, а лишнее время паузой.

                      

                    

                    

                      
Дожимать длину вторым запросомРеплики, не попавшие в слот, переписываются ещё раз.

                      

                    

                  

                


                
                

                  Голос
                  

                    
Движок синтезаБазовый голос дубляжа. piper работает везде; silero даёт 34 русских голоса вместо четырёх и быстрее — на сервере считается там, а без сервера ему нужен Python с torch.

                    

                      
                    

                  

                  

                    
Голос по умолчаниюРусские голоса piper. Работают без сети.

                    

                      
                      
                    

                  

                  

                    
Голоса персонажейМногоголосый дубляж раздаёт голоса по полу говорящих; одноголосый читает весь фильм голосом по умолчанию.

                    

                      
                    

                  

                  

                    
Голоса актёровНужен сервер с видеокартой — раздел «Вычисления».Реплика звучит голосом того, кто говорит в оригинале. Считается на сервере с видеокартой (X-Voice), образцы голосов снимаются с отделённой дорожки голоса. Движок выше остаётся: по нему подгонка решает длину реплик, и им говорят персонажи, для которых образца нет. Веса X-Voice — под некоммерческой лицензией (CC BY-NC): только для личного использования.

                    

                  

                  

                    
Качество голосов актёровШаги модели: 32 — лучше звучит, около полутора секунд на реплику; 16 — вдвое быстрее.

                    

                      
                    

                  

                  

                    
Проверять голоса актёровСервер распознаёт каждую озвученную реплику; если в начале лишний звук или пропало слово, реплика озвучивается заново — до трёх попыток. Озвучка голосами дольше примерно на треть.

                    

                  

                  
                


                
                

                  Распознавание речи
                  

                    
Модель WhisperКрупнее — точнее и медленнее. Веса загружаются при первом использовании.

                    

                      
                    

                  

                  

                    
Язык оригиналаНа каком языке говорят в оригинале.

                    

                  

                  

                    
Уточнять границы реплик по речиПодтягивает начало и конец к реальной речи. Отключать не стоит.

                    

                  

                  

                    
Разные голоса для персонажейОпределяет, кто говорит, и раздаёт голоса по персонажам. Без этого весь фильм читает один голос.

                    

                  

                


                
                

                  Звук
                  

                    
Убирать оригинальную речь из фонограммыОтделяет голос от музыки нейросетью: музыка и шумы остаются, исходная речь уходит. Нужно и для голосов актёров — образцы снимаются с отделённой дорожки. Без этого оригинал просто приглушается под русской речью.

                    

                  

                  

                    
Что делать с оригиналомУбирать исходный голос только под русской речью — тогда музыка не приседает, а песня без дубляжа сохраняет вокал. Либо заменить оригинал фоном на весь фильм: голос уйдёт везде, но песни лишатся вокала.

                    

                      
                    

                  

                  

                    
Подложка исходного голосаСколько исходного голоса оставить под русской речью. Полная тишина звучит стерильно: вместе с голосом уходят дыхание и отзвук комнаты.

                    

                      
                    

                  

                  

                    
Громкость фона

                    

                  

                  

                    
Громкость дубляжа

                    

                  

                  

                    
Выравнивать громкость итогаНормализация по стандарту вещания (EBU R128).

                    

                  

                  

                    
Оставлять оригинальную дорожкуВ итоговом файле будет две дорожки: русская и исходная — переключаются в плеере.

                    

                  

                


                
                

                  Подгонка по времени
                  

                    
Подгонять реплики под таймкодыУскорение, сокращение и разведение наложений. Без этого реплики кладутся как есть.

                    

                  

                  

                    
Максимальное ускорение

                    

                  

                  

                    
Попыток сократить репликуСколько раз просить модель укоротить текст, если он не влезает.

                    

                  

                  

                    
Предел сдвига реплики, мсНасколько реплика может опоздать, чтобы не наехать на предыдущую.

                    

                  

                


                
                

                  Загрузки
                  
Значения по умолчанию для ссылок. На вкладке «Загрузки» их можно переопределить для одного раза.

                  

                    
КачествоДля дубляжа важно только разрешение файла: видео копируется без перекодирования. «Только звук» хватает для субтитров.

                    

                  

                  

                    
КонтейнерВо что сводить дорожки видео и звука. mkv терпимее к редким кодекам.

                    

                  

                  

                    
ПлейлистЧто делать, если ссылка ведёт на список видео.

                    

                  

                  

                    
Папка для скачанногоПусто — рабочая папка библиотеки. Скачанное переживает очистку кэша.

                    

                  

                  

                    
Вписывать данные в файлНазвание, канал, дата и ссылка на источник внутри файла. Без этого плеер покажет его безымянным. Стоит одного прохода перепаковки без перекодирования.

                    

                  

                  

                    
Вкладывать обложкуКартинка ролика внутри файла: видна в проводнике и плеере. Тот же проход, что и у данных.

                    

                  

                  

                    Дополнительно
                  

                    
Фрагментов одновременноСколько частей файла тянуть сразу. Помогает на быстром канале.

                    

                  

                  

                    
Сохранять превьюКартинка ролика рядом с видеофайлом.

                    

                  

                  

                    
Вкладывать главыПометки глав из описания ролика. Нужны длинным лекциям и подкастам, у коротких роликов их нет.

                    

                  

                  

                    
Скачивать субтитры YouTubeОригинальные субтитры рядом с видео. Языки — в config.yaml, поле subtitle_languages. Для дубляжа они не используются: речь распознаёт Whisper.

                    

                  

                  

                    
Напоминать об обновлении yt-dlpYouTube меняется, и загрузчик старше 45 дней перестаёт работать. Обновление: dub tools update yt-dlp.

                    

                  

                  

                    
Куки браузераНужны только для видео с возрастным ограничением и проверки «вы не робот». Это доступ к аккаунту.

                    

                  

                  

                    
Файл cookies.txtПуть вместо браузера, для тех, кто не хочет пускать программу в браузер. DubPipe сам этот файл не читает — его открывает только yt-dlp.
