                  Перевод

                  

                    
Где переводитьОблачная модель качественнее и требует ключ. Локальный вариант работает без сети через Ollama.

                    

                      
                      
                    

                  


                  

                    
Ключ доступаКлюч Kilo Code. Хранится на этом компьютере отдельно от настроек и никуда не передаётся, кроме шлюза.

                    

                      

                        
                        
                      

                      

                        
                        
                        
                        
                      

                    

                  


                  

                    
МодельВесь каталог шлюза Kilo Code; цена — за миллион токенов запроса / ответа. Сравнить несколько на своём видео можно на странице файла.

                    

                      

                        
                        

                      

                      

                        
                        
                        
                      

                      

                    

                  


                  

                    
Локальная модель OllamaДолжна быть установлена: ollama pull имя.

                    

                  


                  

                    
Ненормативная лексикаКак переводить брань в оригинале.

                    

                      
                    

                  


                  

                    Тонкая настройка
                    

                      
Реплик в одном запросе8–12 — рекомендуемый диапазон.

                      

                    

                    

                      
Темп речи, символов в секундуОриентир для подбора длины перевода. Фактический темп показывается после синтеза.

                      

                    

                    

                      
Дожимать длину вторым запросомРеплики, не попавшие в слот, переписываются ещё раз.

                      

                    

                  

                


                
                

                  Голос
                  

                    
Голоса персонажейМногоголосый дубляж раздаёт голоса по полу говорящих; одноголосый читает весь фильм голосом по умолчанию.

                    

                      
                    

                  

                  

                    
Голос по умолчаниюРусские голоса piper. Работают без сети.

                    

                      
                      
                    

                  

                  

                    
Голоса спикеровКогда в видео несколько говорящих, каждому можно назначить свой голос. Пока диаризация не подключена, все реплики идут как speaker_0.

                    

                  

                  
                


                
                

                  Распознавание речи
                  

                    
Модель WhisperКрупнее — точнее и медленнее. Веса загружаются при первом использовании.

                    

                      
                    

                  

                  

                    
Чем считать распознаваниеСборка whisper.cpp. Автоматически выбирается официальная под ваше железо. Vulkan работает на видеокартах AMD и Intel и вдвое быстрее, но собран не проектом whisper.cpp.

                    

                      
                    

                  

                  

                    
Язык оригиналаНа каком языке говорят в оригинале.

                    

                  

                  

                    
Уточнять границы реплик по речиПодтягивает начало и конец к реальной речи. Отключать не стоит.

                    

                  

                  

                    
Разные голоса для персонажейОпределяет, кто говорит (pyannote, локально на процессоре), и раздаёт голоса по спикерам — см. «Голоса». Нужен Python и однократная загрузка модели.

                    

                  

                  

                    
Где считать голосаНа видеокарте вчетверо быстрее, если установлен onnxruntime-directml. Результат тот же.

                    

                      
                    

                  

                  

                    
Токен Hugging FaceНужен один раз — скачать веса модели. Бесплатный, с правом чтения. Перед этим примите условия на странице модели pyannote/speaker-diarization-community-1 (huggingface.co). Хранится на этом компьютере, в файл настроек не попадает.

                    

                      

                        
                        
                      

                      

                        
                        
                        
                      

                    

                  

                


                
                

                  Звук
                  

                    
Убирать оригинальную речь из фонограммыОтделяет голос от музыки нейросетью. Заметно дольше, нужен Python с numpy и onnxruntime. Иначе оригинал просто приглушается на время реплик.

                    

                  

                  

                    
Что делать с оригиналомУбирать исходный голос только под русской речью — тогда музыка не приседает, а песня без дубляжа сохраняет вокал. Либо заменить оригинал фоном на весь фильм: голос уйдёт везде, но песни лишатся вокала.

                    

                      
                    

                  

                  

                    
Подложка исходного голосаСколько исходного голоса оставить под русской речью. Полная тишина звучит стерильно: вместе с голосом уходят дыхание и отзвук комнаты.

                    

                      
                    

                  

                  

                    
Где считать отделениеНа видеокарте впятеро быстрее: минута звука за три секунды вместо семнадцати.

                    

                      
                    

                  

                  

                    
Громкость фона

                    

                  

                  

                    
Громкость дубляжа

                    

                  

                  

                    
Выравнивать громкость итогаНормализация по стандарту вещания (EBU R128).

                    

                  

                  

                    
Оставлять оригинальную дорожкуВ итоговом файле будет две дорожки: русская и исходная — переключаются в плеере.

                    

                  

                


                
                

                  Подгонка по времени
                  

                    
Подгонять реплики под таймкодыУскорение, сокращение и разведение наложений. Без этого реплики кладутся как есть.

                    

                  

                  

                    
Максимальное ускорение

                    

                  

                  

                    
Попыток сократить репликуСколько раз просить модель укоротить текст, если он не влезает.

                    

                  

                  

                    
Предел сдвига реплики, мсНасколько реплика может опоздать, чтобы не наехать на предыдущую.
