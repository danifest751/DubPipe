# Генерация на домашнем сервере

Оба исходных промпта из ../prompts.md отправлены без сокращений и переформулировки. Совпадение текстов проверено. Генерация выполнена на пользовательском сервере me4me через ComfyUI, а не через встроенный ImageGen.

- Модель: Qwen-Image 2512 FP8.
- Ускорение: Qwen-Image-2512-Lightning-4steps-V1.0, сила 1.0.
- Размер: 1536 × 960.
- Сэмплер: Euler, simple, 4 шага, CFG 1.0, shift 3.1.
- Главный экран: 01-library.png, seed 930261, около 139 секунд с подготовкой моделей.
- Дубляж: 02-dubbing.png, seed 930262, около 70 секунд.
- Серверные оригиналы: comfyui/output/dubpipe-design/2026-09-30/.

Рядом сохранены графы ComfyUI, идентификаторы заданий, история выполнения и скрипт generate.py. Секреты для генерации не требовались: использован локальный API.

## Проверка качества

Оба изображения открыты и проверены. Модель сохранила общую тёмную палитру и название DubPipe, но нарушила существенные требования: добавила ноутбук, декоративные шары и фиолетовые элементы, исказила кириллицу и изменила компоновку экранов. Это исходные результаты одинаковых промптов для сравнения моделей, не утверждённый дизайн. Причина потери деталей отдельно не установлена. Для улучшения потребуется отдельный запуск с адаптацией промпта под локальную модель.

## Повторный запуск

Нужен ComfyUI с моделями и узлами, перечисленными в сохранённом workflow.
Адрес задаётся через `COMFYUI_URL`; по умолчанию — `http://127.0.0.1:8188`.
Например, в PowerShell из корня репозитория:

```powershell
$env:COMFYUI_URL = "http://GPU_HOST:8188"
python design/concepts/2026-09-30-mint-studio/server-qwen/generate.py
```

Скрипт запускает генерацию на указанном сервере и перезаписывает PNG и JSON рядом
с собой. Для сохранения этого архивного запуска сначала скопируйте каталог.
Это вспомогательный эксперимент дизайна, а не часть runtime DubPipe.
