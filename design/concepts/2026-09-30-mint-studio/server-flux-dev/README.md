# FLUX.2 dev на домашнем сервере

Оба исходных промпта из ../prompts.md использованы без сокращений и переформулировки; совпадение текстов проверено. Генерация выполнена через ComfyUI на пользовательском сервере me4me, без встроенного ImageGen.

- Модель: FLUX.2 dev 32B, GGUF Q3_K_M.
- Кодировщик: Mistral Small, FP8, тип flux2.
- LoRA: Flux2TurboComfyv2, сила 1.0.
- Размер: 1536 × 960.
- 8 шагов, Euler, Flux2Scheduler, guidance 2.5.
- VAE: flux2-vae.safetensors.
- Seed главного экрана: 930261, дубляжа: 930262.

Сначала оба промпта закодированы за 61 секунду через CondCacheSave. Затем изображения построены с CondCacheLoad: главный экран — 160 секунд, дубляж — 123 секунды. Серверные оригиналы лежат в comfyui/output/dubpipe-design/2026-09-30-flux-dev/. Локальные PNG, графы ComfyUI, история выполнения, идентификаторы заданий и generate.py сохранены рядом.

## Визуальная проверка

Оба PNG открыты и проверены, размер подтверждён. В этой паре результатов FLUX лучше Qwen сохранила структуру экранов, мятно-графитовую палитру, требуемые превью, персонажей и часть русских надписей. Однако кириллица местами искажена, пункты навигации и панели повторяются, есть лишняя светлая рамка. Это концептуальные изображения, не готовый интерфейс. Сравнение относится к конкретным запускам квантованных моделей с ускоряющими LoRA, а не к качеству всех вариантов FLUX и Qwen.

## Повторный запуск

Нужен ComfyUI с моделями и узлами, перечисленными в сохранённом workflow.
Адрес задаётся через `COMFYUI_URL`; по умолчанию — `http://127.0.0.1:8188`.
Например, в PowerShell из корня репозитория:

```powershell
$env:COMFYUI_URL = "http://GPU_HOST:8188"
python design/concepts/2026-09-30-mint-studio/server-flux-dev/generate.py
```

Скрипт запускает генерацию на указанном сервере и перезаписывает PNG и JSON рядом
с собой. Для сохранения этого архивного запуска сначала скопируйте каталог.
Это вспомогательный эксперимент дизайна, а не часть runtime DubPipe.
