# Альтернатива: тёплая студия

Два макета созданы встроенным ImageGen 30.09.2026. `01-library.png` показывает
библиотеку, `02-dubbing.png` — работу с репликой. Промпты сохранены в `prompts.json`.
Палитра: фарфоровый фон, угольный текст и терракотовый акцент.

Это архив альтернативного направления. Для приложения выбраны первые два макета
[мятной студии](../2026-09-30-mint-studio/README.md). Тёплая палитра, таймлайн и
предложенный на этих изображениях редактор в код не перенесены. Названия видео,
персонажи и показатели на картинках демонстрационные.
