## Как сообщить об уязвимости

Сообщайте об уязвимостях **приватно**, а не через публичные issue.

- Используйте [приватные сообщения о уязвимостях](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
  в GitHub — кнопка «Report a vulnerability» на вкладке Security.
- Опишите, что вы сделали, что произошло и чего вы ожидали; лучше всего помогает
  минимальный пример воспроизведения.
- Первый ответ — примерно в течение недели. Проект ведёт один человек, наберитесь терпения.

Не прикладывайте к отчёту настоящие ключи, токены и личный видеоматериал. Если дело
касается ключа — сначала отзовите его, а в отчёте опишите ситуацию.

## Поддерживаемые версии

Поддерживается последняя версия в ветке `main`. Для старых версий исправления не выпускаются.

## Что программа делает с вашими данными

- **Всё выполняется локально**, кроме перевода. Аудио и видео не покидают машину.
- В профиле `hybrid` на шлюз перевода уходит только **текст** распознанных реплик.
  В профиле `offline` после загрузки моделей наружу не уходит ничего.
- **Ключи** (ключ шлюза перевода, токен Hugging Face) хранятся в `secrets.json` в каталоге
  кэша, а не в `config.yaml`. В веб-интерфейс ключ передаётся только в маскированном виде,
  никогда целиком, поэтому `config.yaml` можно спокойно пересылать. Схема настроек не
  принимает ключ там, где ожидается имя переменной: такой файл лечится, а значение
  переносится в хранилище ключей.
- **Локальный сервер** слушает только `127.0.0.1` на случайном порту, на каждый запуск
  выдаёт одноразовый токен, требует его для всех запросов `/api/*` и отказывается читать
  или отдавать пути вне рабочего каталога и каталога кэша.

## Известные зоны риска

Это свойства самой задачи — они описаны, а не скрыты:

- Загружаемые компоненты (ffmpeg, модели, голоса) скачиваются по HTTPS с сайтов
  первоисточников и проверяются только по размеру, без проверки подписи. Если в вашей среде
  это важно, используйте собственные зеркала.
- Необязательная стадия диаризации при нажатии кнопки загрузки ставит `pyannote.audio`
  через pip в активное окружение Python. Если это нежелательно, используйте виртуальное
  окружение.
- Сборка для Windows не подписана сертификатом, поэтому SmartScreen показывает
  предупреждение.
